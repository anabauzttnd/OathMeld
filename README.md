# OathMeld

A simple OathMeld engine for real time data processing.

OathMeld is aimed at developers who need a straightforward, dependable solution.

**Highlights**

- A simple OathMeld engine for
- real time data processing

## Technology Stack

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/OathMeld.git`
2. `cd OathMeld`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
